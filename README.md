# Автоматизированный анализ динамической функциональной связности головного мозга по данным ЭЭГ

Программный комплекс для автоматической предобработки сигналов ЭЭГ, реконструкции плотности распределения корковых источников методом sLORETA и классификации функциональных состояний с использованием пространственно-временных графовых нейронных сетей (ST-GCN).
